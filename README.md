# 🎮 Moteur de Jeu 2D - C++ & SDL2

**Moteur de jeu vidéo 2D** développé en C++ avec SDL2. Implémentation complète d'un système de gameplay avec personnages, ennemis IA, niveaux dynamiques et gestion d'objets interactifs.

## Compétences techniques

**Programmation** : C++, POO avancée (héritage, polymorphisme), gestion mémoire  
**Graphisme** : SDL2, sprites, spritesheets, rendering optimisé  
**Architecture** : Design patterns (Game Loop, Entity-Component), modularité  
**Algorithmique** : IA ennemis, collisions, parsing de fichiers  
**Outils** : Git, CodeBlocks

## Stack

`C++17` • `SDL2` • `SDL2_image` • `Git` 


## Architecture

```
Personnage (abstract) → Avatar, Ennemi
Moteur : SDL2 rendering & events
Niveau : Parsing & gestion dynamique
Image : Sprites & ressources graphiques
```

**10 classes C++** | **Système modulaire** | **Assets configurables**
